GitHub 私有仓库

把对话、任务、记忆存到你自己的私有仓库。手机和电脑填同一个 token，数据就同步了。token 只存本机，不进代码。

需要 fine-grained PAT，勾选仓库 1yk8u/xiaozhi-studio-data 的 Contents: read and write。

怎么生成令牌？
  1. 打开 GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Generate new token，Repository access 选「Only select repositories」勾选 xiaozhi-studio-data
  3. Permissions → Contents 设为 Read and write
  4. 生成后复制 github_pat_ 开头的串，粘到上面保存
